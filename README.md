# ShopStack API

![CI](https://github.com/idrismuhd41/shopstack-api/actions/workflows/ci.yml/badge.svg)

Production-oriented e-commerce backend built with Node.js, TypeScript, Express, PostgreSQL, and Prisma.

## Task Coverage

Built for the **Elevvo Backend Development Internship** (1-month). Implements 4 tasks:

| Task | Focus |
|------|-------|
| Task 3 | Modular Express API, observability, API-key auth |
| Task 4 | JWT auth, bcrypt, RBAC, rate limiting |
| Task 5 | PostgreSQL + Prisma, transactions, pagination |
| Task 7 | Docker multi-stage, Jest tests, GitHub Actions |
